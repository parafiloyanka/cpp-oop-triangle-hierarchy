# C++ OOP Hierarchy: Triad to Triangle 📐

Консольна програма мовою C++ для демонстрації принципів об'єктно-орієнтованого програмування, зокрема **успадкування** класів. Проєкт реалізує ієрархію від базового класу `Triad` (трійка чисел) до похідного `Triangle` (трикутник).

## ⚙️ Основний функціонал
- **Успадкування класів:** Використання базового класу для зберігання трьох величин та розширення його логіки у похідному класі геометричної фігури.
- **Валідація даних:** Перевірка введених користувачем сторін на відповідність теоремі про нерівність трикутника (сума двох сторін має бути строго більшою за третю).
- **Алгоритм автовиправлення:** Унікальна функція автоматичного коригування довжини сторін (зменшення необхідної сторони), якщо з початкових даних неможливо побудувати фігуру.
- **Захист від помилок:** Обробка некоректного вводу (літер, від'ємних значень або нулів) за допомогою очищення буфера потоку `cin`.
